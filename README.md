# wakastats

![Image of GNOME shell with wakastats extension enabled](wakastats.png)

A simple GNOME shell extension displaying wakatime today data

## Installations

This extension supports only GNOME 50+
Check your GNOME version with

```bash
gnome-shell --version
```
